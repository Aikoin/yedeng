<h1 align="center">页灯 YEDENG</h1>
<p align="center">照亮难懂的一页 · 使用自己的 AI 服务精读论文</p>

页灯是一款 Chrome Manifest V3 扩展，将 PDF 阅读、AI 解释和阅读笔记放在同一界面。你自行配置 OpenAI 兼容接口与 API Key；论文、标注和已保存结果保存在当前浏览器本机。

## 功能

- 自渲染 PDF 阅读器：文字选取、高亮、划线、笔记、搜索与来源定位。
- **概览 / 提问 / 笔记**三处主入口；打开论文后自动生成摘要与关键词，可在阅读偏好关闭，逐节摘要按需生成。
- 划词或划句直接解释、翻译；问答优先提供完整可提取文字（不超过 60,000 字符时）；长论文综合相关页、相邻上下文和关键章节，按问题类型分配 40,000–60,000 字符。概念解释可补充通用知识，本文结论仍需原文支持。
- 划线解释完成后自动保存到「笔记 → 解读」，保留原文、页码及后续追问；重新打开可继续提问，保存不受缓存开关影响。旧版已保存回答也可查看，但无法恢复旧版未保存的原文。
- 图表框选后保存、解读、置顶参考，并支持删除、撤销与回收站恢复。
- 公式框选后直接讲解；首次“复制公式”先识别为 LaTeX，之后使用本地结果。支持跨页原图、修改、原图校对和编辑记录。
- 文献库、离线留存、同字节识别、Markdown 与原图导出、数据备份与恢复。
- 文本模型可选择；图像请求使用单独的 Flash 视觉路由。第三方服务需要填写其实际支持的视觉模型。

**复杂公式识别仍需人工对照原图。** 上下标、粗体、矩阵、跨页表达式可能识别错误；本项目不承诺公式转写或 AI 解释始终正确。

## 本地安装

需要 Node.js 22.12+ 和 pnpm 10。

```bash
git clone https://github.com/Aikoin/yedeng.git
cd yedeng
pnpm install --frozen-lockfile
pnpm build
```

1. 打开 Chrome 的 `chrome://extensions`，开启“开发者模式”。
2. 选择“加载已解压的扩展程序”，选取本项目的 `dist` 文件夹。
3. 首次打开配置引导，填写服务商 Base URL、API Key 和文本模型；需要图表或公式能力时配置支持图像输入的 Flash 路由。
4. 打开 PDF，通过插件进入页灯；也可在文献库导入本地 PDF。
5. 需要接管 `file://` PDF 时，在扩展详情中开启“允许访问文件网址”。

本项目当前通过本地构建安装，尚未提供 Chrome 应用商店安装。更新源码并重新构建后，在扩展管理页点击“重新加载”，再关闭旧阅读器页面并重新打开。

## 使用

- **概览**：查看摘要、关键词和章节；来源引用代表用于回答的证据，不是公式编号。
- **提问**：围绕当前论文提问，或选中文字后直接解释、翻译。
- **笔记**：统一查看文字、图表和公式，可筛选、恢复删除项目和导出。
- **框选公式**：拖拽框选后直接进入公式详情，选择“讲解这个公式”或“复制公式”。无需先识别才能讲解。
- **框选图表**：拖拽后保存，进入图表详情解读或置顶；取消置顶不会删除已保存图表。

## 隐私与费用

- 仓库不提供 API Key，不需要项目方账号，也不包含开发者的浏览器数据或个人论文。
- API Key 存在 `chrome.storage.local` 中，属于本机配置，**不是加密保险箱**。勿把浏览器配置文件、原始配置导出或完整备份上传到公开仓库。
- 使用 AI 时，所选文字、检索出的相关片段或局部原图会发送到**你配置的服务商**。自动概览开启且论文允许 AI 时，打开论文可能产生请求和费用；缓存命中时复用已保存结果。
- “数据保存在本机”并不表示 AI 推理在本机完成。服务商的数据处理和计费规则由你选择的服务决定。
- 不需要 AI 时可以跳过配置继续阅读、标注。更多说明见 [隐私说明](PRIVACY.md)。

## 开发与验证

```bash
pnpm typecheck
pnpm test
pnpm build
```

`pnpm dev` 会持续构建，修改后需重新加载扩展。单元测试使用合成数据和模拟请求，不需要真实 Key。问答未集成联网搜索；回答的“来源与范围”会注明可提取全文或跨章节选段，不能将模型背景知识理解为联网核验。`pnpm smoke` 是可选的独立 Chrome 冒烟脚本，需要本机安装 Chrome；不属于单元测试默认流程。

目录：`src/pdf` 为 PDF 渲染和选区，`src/ai` 为上下文与调用路由，`src/viewer` 为阅读交互，`src/formula` 为公式，`src/evidence` 为原图证据，`src/storage` 为导出备份，`tests` 为合成测试。

请勿提交 `.env`、API Key、模型响应日志、个人文献或备份。提交问题前请删除截图中的密钥、私人链接和论文信息。参见 [贡献说明](CONTRIBUTING.md) 与 [安全说明](SECURITY.md)。
